| Параметр | Значение |
|---|---|
| Проект | LifeTrack |
| Документ | UI Design (визуальная концепция и спецификация интерфейса) |
| Версия документа | 1.0 |
| Дата | 29.10.2026 |
| Связанные документы | `docs/TECHNICAL_SPECIFICATION.md`, `docs/USER_STORY_MAP.md` |
| Технологическая база | Jetpack Compose, Material 3, Navigation Compose |

Документ описывает внешний вид и поведение интерфейса версии 1.0. Состав экранов, маршруты и правила навигации взяты из раздела 6 технического задания; требования к состояниям — из NFR-4.4.

## 1. Общий стиль

### 1.1. Принципы

1. **Одна задача на экран.** Главный экран отвечает за отметки, календарь — за обзор, статистика — за цифры. Элементы разных задач не смешиваются.
2. **Минимум действий.** Ежедневная отметка — одно нажатие на карточке, без открытия диалогов и подтверждений.
3. **Спокойный фон, акцент на данных.** Интерфейс нейтральный; цветными остаются привычки, прогресс и статусы.
4. **Понятная иерархия.** Заголовок экрана → блок итогов → список карточек → действия. Размер и вес шрифта отражают уровень, а не декоративность.
5. **Предсказуемость.** Одинаковые элементы выглядят и ведут себя одинаково на всех экранах: карточка привычки, чип, пустое состояние, диалог подтверждения.
6. **Доступность по умолчанию.** Контраст не ниже WCAG AA, размер интерактивных элементов не менее 48×48 dp, статусы дублируются текстом или иконкой.
7. **Без украшений.** Нет градиентных фонов, тяжёлых теней, стеклянных эффектов и анимаций дольше 300 мс.

### 1.2. Сетка и отступы

| Параметр | Значение | Применение |
|---|---|---|
| Базовый шаг | 4 dp | Внутренние интервалы между иконкой и текстом |
| Отступ экрана | 16 dp | Поля содержимого слева и справа |
| Отступ между секциями | 24 dp | Разделы формы, блоки статистики |
| Отступ между карточками | 8 dp | Списки привычек, карточки метрик |
| Внутренний отступ карточки | 16 dp | Все карточки и панели |
| Отступ иконки от текста | 16 dp | Карточка привычки, элемент настройки |
| Высота нижней панели | 80 dp | `NavigationBar` с учётом системной вставки |
| Минимальная зона нажатия | 48×48 dp | Кнопки-иконки, круги отметки, чипы |

Минимальный размер интерактивной области — 48×48 dp, даже если визуальный элемент меньше: чип высотой 32 dp, круг отметки 40 dp в нижнем листе, иконка 24 dp и ячейка календаря получают область нажатия не менее 48×48 dp через `minimumInteractiveComponentSize` или внешний отступ. Визуальный размер элемента при этом не увеличивается.

Контент выравнивается по левому краю; числа в метриках — по левому краю внутри карточки, чтобы значения образовывали вертикальную колонку.

### 1.3. Формы, радиусы и тени

| Элемент | Радиус | Тень / граница |
|---|---|---|
| Карточка привычки | 16 dp | Без тени, фон `Surface`, тонкая граница `OutlineVariant` 1 dp |
| Карточка метрики | 16 dp | Без тени, фон `SurfaceVariant` |
| Карточка достижения | 20 dp | Без тени, фон `Surface` |
| Поле ввода | 12 dp | Обводка `Outline`, при фокусе — `Primary` 2 dp |
| Кнопка | 24 dp (полная) | Без тени |
| Нижний лист | 28 dp сверху | Тень `Level 2` |
| Чип | 8 dp | Фон `SurfaceVariant`, выбранный — `SecondaryContainer` |
| Круг отметки | 24 dp (диаметр 48 dp) | Обводка 2 dp, заполнение при выполнении |

Тени используются только у нижнего листа, диалогов и FAB. Плоские поверхности разделяются цветом и границей — это упрощает отрисовку и сохраняет читаемость в тёмной теме.

### 1.4. Иконки

- Стиль: линейные иконки Material, толщина штриха 2 dp, размер 24 dp (в карточке привычки — 24 dp внутри цветного круга 40 dp).
- Иконки без текста всегда имеют `contentDescription`; декоративные — `null`.
- Набор иконок привычек соответствует разделу 9.3 ТЗ; при неизвестном ключе отображается `star`.
- Иконки нижней навигации: «Сегодня» — `Today`, «Календарь» — `CalendarMonth`, «Статистика» — `Insights`, «Достижения» — `EmojiEvents`. Если иконка отсутствует в базовом наборе без дополнительной зависимости, используется ближайший доступный эквивалент (`Home`, `DateRange`, `List`, `Star`).

### 1.5. Обязательные состояния

Для каждого экрана и компонента предусмотрены:

| Состояние | Оформление |
|---|---|
| Загрузка | Скелетон из 3–5 блоков `SurfaceVariant` с плавным пульсированием или `CircularProgressIndicator` по центру, если данных нет вовсе |
| Пустые данные | Иконка 48 dp, заголовок `titleMedium`, пояснение `bodyMedium`, одна кнопка действия |
| Ошибка | Иконка предупреждения, текст ошибки, кнопка «Повторить» |
| Нажатие | Затемнение фона на 8 % (`ripple`), без изменения размера |
| Недоступно | Прозрачность 38 %, без реакции на нажатие |

Состояние «Недоступно» применяется к кнопке «Сохранить» при невалидной форме и к действиям отметки для незапланированных дней.

### 2.4. Правила использования цвета

1. Чистый чёрный (`#000000`) и чистый белый фон в тёмной теме не используются.
2. Акцентный цвет применяется к одному главному действию экрана; остальные действия — вторичные или текстовые.
3. Цвет привычки задаётся пользователем из палитры раздела 9.3 ТЗ и не меняется при переключении темы. Для тёмной темы выполняется только корректировка отрисовки: насыщенность ограничивается, при необходимости яркость повышается до контраста не ниже 3 : 1 с фоном `Surface`. Значение в базе остаётся исходным.
4. Динамическая палитра (Monet) не используется: `dynamicColor` выключен (FR-4.11.3).
5. Статусы используют фиксированные семантические цвета, а не цвет привычки: «Выполнено» — Success, «Пропущено» — Error, «Не отмечено» — Outline, «Не запланировано» — OnSurfaceVariant на SurfaceVariant.
6. Цвет не является единственным носителем информации: рядом со статусом всегда есть текст или иконка (NFR-9.4).
## 3. Типографика

### 3.1. Базовый шрифт

Используется системный шрифт Roboto из стандартной типографики Material 3. Дополнительные шрифты не подключаются: это сохраняет единообразие между устройствами и не увеличивает размер APK. Курсив и декоративные начертания не используются.

### 3.2. Стили текста

| Стиль Material 3 | Размер / интерлиньяж | Насыщенность | Применение |

| `displaySmall` | 36 sp / 44 sp | 400 | Крупный процент выполнения на экране статистики привычки |
| `headlineSmall` | 24 sp / 32 sp | 600 | Заголовки приветственного экрана и пустых состояний |

| `bodyLarge` | 16 sp / 24 sp | 400 | Основной текст, значения полей ввода |
| `bodyMedium` | 14 sp / 20 sp | 400 | Описание привычки, пояснения, текст диалогов |

### 3.3. Правила набора

1. Название привычки в карточке — не более одной строки с многоточием; полное название доступно на подробном экране.
2. Описание привычки выводится в карточке одной строкой с многоточием, если поле заполнено; на подробном экране — до трёх строк с многоточием.
3. Заголовки экранов — одна строка; при системном масштабе шрифта 200 % допускается перенос на две строки без обрезки.
4. Числовые значения не сокращаются: «67 %», «1 234», «7 / 30»; разделитель разрядов — неразрывный пробел.
5. Подписи полей формы располагаются над полем стилем `bodySmall`; текст ошибки — под полем тем же стилем, цвет `Error`.
6. Заголовок и значение метрики отделяются интервалом 4 dp; значение выводится стилем `titleLarge` или `displaySmall`.
7. Все тексты интерфейса хранятся в `strings.xml`; жёстко заданные строки в Compose-коде не допускаются.

## 4. Компоненты

Компоненты переиспользуются на нескольких экранах. Каждый компонент не содержит бизнес-логики: он получает данные и колбэки, а вычисления выполняются во ViewModel или доменном слое.

### 4.1. HabitCard

**Назначение.** Основная единица главного экрана: показывает привычку на сегодня и позволяет отметить выполнение.

**Состав.**
- круг 40 dp с иконкой привычки (фон — цвет привычки с прозрачностью 12 %, иконка — цвет привычки);
- название стилем `titleMedium`, одна строка;
- описание стилем `bodySmall`, одна строка, только если заполнено;
- строка деталей стилем `bodySmall`: периодичность и текущая серия (иконка огня 14 dp и число);
- круг отметки 48 dp справа;
- кнопка «…» 48 dp для контекстного меню.

**Внешний вид.** Карточка высотой не менее 88 dp, радиус 16 dp, фон `Surface`, граница `OutlineVariant` 1 dp, внутренний отступ 16 dp. Расстояние между карточками 8 dp. Порядок элементов в строке: иконка, текстовый блок (занимает всё свободное место), кнопка «…», круг отметки. На экране шириной 320 dp текстовый блок получает не менее 140 dp, длинное название и описание обрезаются многоточием.

**Состояния.**

| Состояние | Круг отметки | Фон карточки | Текст |
|---|---|---|---|
| Не отмечено | Обводка `Outline` 2 dp, внутри пусто | `Surface` | Обычный |
| Выполнено | Заливка `Success`, иконка `Check` белая | `Surface` | Название приглушено (`OnSurfaceVariant`), серия выделена |
| Пропущено | Заливка `ErrorContainer`, иконка «минус» цветом `OnErrorContainer` | `Surface` | Статус «Пропущено» в строке деталей |
| Недоступно (не запланировано) | Круг отсутствует | `SurfaceVariant`, прозрачность 60 % | Приглушённый |
| Приостановлена (режим «Все привычки») | Круг отсутствует | `SurfaceVariant`, прозрачность 60 % | Приглушённый, вместо строки серии — метка «Приостановлена» |

**Взаимодействие.**
- нажатие на карточку открывает подробный экран;
- нажатие на круг создаёт или снимает отметку `DONE`;
- кнопка «…» и долгое нажатие открывают меню: «Отметить пропуск», «Редактировать», «Удалить»;
- для TalkBack действия «Отметить выполнение» и «Отметить пропуск» добавлены как `customActions`, а карточка объединена через `semantics(mergeDescendants = true)`;
- нажатие сопровождается `ripple`; удаление и добавление карточек анимируются (раздел 7).

### 4.2. ProgressIndicator

**Назначение.** Показывает прогресс дня и прогресс выполнения за период.

**Состав и варианты.**
1. **Линейный** — дорожка высотой 8 dp, радиус 4 dp, фон `SurfaceVariant`, заполнение `Primary`; над дорожкой строка «Выполнено 2 из 4» стилем `bodyMedium`, справа процент стилем `labelMedium`.
2. **Круговой** — кольцо диаметром 28 dp, толщина 3 dp; используется в ячейке календаря и в нижнем листе дня.

**Внешний вид.** Заполнение линейного индикатора скруглено с двух сторон, минимальная видимая доля при значении больше нуля — 4 dp, чтобы прогресс был заметен при 1 из 20.

**Состояния.**
- `0 %` — только дорожка, текст «Выполнено 0 из N»;
- частичное заполнение — пропорционально значению, округление до целого процента;
- `100 %` — дорожка заполнена полностью, дополнительно отображается иконка `Check` и текст «Все привычки выполнены»;
- нет данных (`N = 0`) — индикатор скрыт, выводится текст «На сегодня привычек нет».

**Взаимодействие.** Компонент не интерактивен; для TalkBack передаётся описание «Выполнено 2 из 4 привычек, 50 процентов».

### 4.3. CategoryChip

**Назначение.** Выбор категории привычки в форме и компактное отображение категории на подробном экране.

**Состав.** Точка-индикатор цвета категории 8 dp, название категории стилем `labelMedium`, горизонтальные отступы 12 dp, вертикальные 8 dp. Опция «Без категории» выводится без точки.

**Внешний вид.** Высота 32 dp, радиус 8 dp. Невыбранный чип — фон `SurfaceVariant`, текст `OnSurfaceVariant`, без границы. Выбранный — фон `SecondaryContainer`, текст `OnSecondaryContainer`, точка цвета сохраняется. Ряд чипов прокручивается горизонтально, отступ между чипами 8 dp, крайние чипы не обрезаются полями экрана.

**Состояния.**
- не выбран — нейтральный фон;
- выбран — контрастный фон и усиленное начертание текста;
- нажатие — `ripple`, без изменения размера;
- недоступен — прозрачность 38 %.

**Взаимодействие.** Одиночный выбор; повторное нажатие на выбранный чип оставляет выбор без изменений. Выбор категории подставляет её цвет, если пользователь ещё не менял цвет вручную (FR-4.2.2). Для TalkBack чип объявляется как переключатель с состоянием «выбрано».

### 4.4. HabitCalendar

**Назначение.** Месячная сетка активности по всем активным привычкам.

**Состав.**
- заголовок: кнопка «‹» 48 dp, название месяца стилем `titleLarge`, кнопка «›» 48 dp, кнопка «Сегодня» справа;
- строка дней недели: «Пн … Вс» стилем `bodySmall`, цвет `OnSurfaceVariant`, высота 24 dp;
- сетка 7 столбцов и до 6 строк, ячейка квадратная со стороной не менее 40 dp, между ячейками 4 dp;
- легенда под сеткой: четыре образца с подписями «Все выполнены», «Частично», «Есть пропуски», «Нет отметок».

**Внешний вид ячейки.**

| Состояние дня | Отображение |
|---|---|
| Вне периода или нет запланированных привычек | Номер цветом `OnSurfaceVariant` с прозрачностью 50 %, без обводки |
| Все запланированные выполнены | Круг, залитый `Primary`, номер `OnPrimary` |
| Выполнена часть | Круговой индикатор `Primary` по контуру `SurfaceVariant`, номер `OnSurface` |
| Есть пропуски, выполнений нет | Круг с обводкой `Error` 2 dp и точкой `Error` в нижней части |
| Отметок нет | Круг с обводкой `Outline` 1,5 dp |
| Сегодня | Дополнительное кольцо `Secondary` 2 dp на расстоянии 2 dp от основного круга |
| Выбранный день | Фон `PrimaryContainer`, номер `OnPrimaryContainer` |

Будущие дни отображаются только с обводкой и расписанием; нажатие на них разрешено, отметки — нет.

**Состояния.** Загрузка — сетка-скелетон без номеров; отсутствие отметок при наличии привычек — сетка остаётся видимой, ячейки показывают контурные круги, под сеткой легенда и подпись «В этом месяце ещё нет отметок»; привычек нет вовсе — вместо сетки `EmptyState` с кнопкой «Создать привычку»; ошибка — сообщение и кнопка «Повторить».

**Взаимодействие.** Нажатие на день открывает `DayBottomSheet`. Свайп влево или вправо по сетке переключает месяц. Кнопка «Сегодня» возвращает текущий месяц. Каждая ячейка имеет `contentDescription`: «14 октября, выполнено 2 из 3 привычек».

### 4.5. StatisticsCard

**Назначение.** Отображение одной числовой метрики на экранах статистики.

**Состав.** Подпись метрики стилем `bodySmall` цветом `OnSurfaceVariant`, значение стилем `titleLarge` (для главной метрики — `displaySmall`), при необходимости — вторая строка-пояснение стилем `bodySmall` и иконка динамики 16 dp.

**Внешний вид.** Радиус 16 dp, фон `SurfaceVariant`, внутренний отступ 16 dp, минимальная высота 88 dp. Главная карточка процента занимает всю ширину и использует фон `PrimaryContainer`; остальные карточки располагаются по две в ряд с отступом 8 dp.

**Состояния.**
- значение есть — число и подпись;
- значения нет — прочерк «—» цветом `OnSurfaceVariant` и пояснение «Нет данных за период»;
- загрузка — прямоугольники-скелетоны вместо текста;
- ошибка — прочерк и иконка предупреждения в углу.

**Взаимодействие.** Карточки метрик не нажимаются. Исключение — карточка привычки в списке статистики: она открывает статистику привычки и визуально отличается шевроном «›», фоном `Surface` и границей.

### 4.6. AchievementCard

**Назначение.** Отображение достижения и прогресса до его получения.

**Состав.** Иконка достижения 32 dp в круге 56 dp, название стилем `titleMedium` (до двух строк), описание условия стилем `bodySmall` (до двух строк), прогресс-бар высотой 6 dp с подписью «3 / 7», дата получения стилем `labelSmall` для открытых достижений.

**Внешний вид.** Карточка в сетке из двух колонок, радиус 20 dp, внутренний отступ 16 dp, минимальная высота 168 dp, фон `Surface`, граница `OutlineVariant`. Открытое достижение: круг иконки — `PrimaryContainer`, иконка `Primary`, дата получения — `Success`. Закрытое: круг `SurfaceVariant`, иконка `OnSurfaceVariant` с прозрачностью 60 %, без границы, текст приглушён; иконка дополнительно перечёркнута диагональной линией 1 dp.

**Состояния.**
- открыто — цветная иконка и дата получения;
- закрыто, прогресс есть — прогресс-бар и «X / Y»;
- закрыто, условие-флаг — без прогресс-бара, только описание условия;
- загрузка — карточка-скелетон;
- новое достижение — бейдж «Новое» в правом верхнем углу в течение текущей сессии.

**Взаимодействие.** Нажатие открывает диалог с подробным условием. Карточка читается TalkBack одним элементом: «Неделя силы, закрыто, 3 из 7».

### 4.7. ReminderTimePicker

**Назначение.** Включение напоминания и выбор времени в форме привычки.

**Состав.** Строка с заголовком «Напоминание» стилем `titleSmall` и переключателем `Switch` справа; под строкой — поле времени «07:30» стилем `bodyLarge` с иконкой часов; при включённом переключателе поле активно.

**Внешний вид.** Блок внутри карточки формы, отделённый `HorizontalDivider` цветом `OutlineVariant`. Поле времени — `OutlinedTextField` только для чтения, высота 56 dp, радиус 12 dp.

**Состояния.**
- выключено — поле показано с прозрачностью 38 %, время сохраняется для следующего включения;
- включено — поле активно, значение по умолчанию 09:00;
- диалог выбора — `TimePickerDialog` Material 3 в 24-часовом формате с кнопками «Отмена» и «ОК»;
- нет разрешения на уведомления — под блоком плашка `WarningContainer` «Уведомления отключены в системе» с кнопкой «Открыть настройки приложения».

**Взаимодействие.** Переключатель включает и выключает напоминание без немедленного сохранения: изменения применяются по кнопке «Сохранить». Нажатие на поле открывает диалог; подтверждение — кнопка «ОК», отмена возвращает прежнее значение. Время отображается в 24-часовом формате независимо от системной настройки.

### 4.8. EmptyState

**Состав.** Иконка 48 dp цветом `OnSurfaceVariant`, заголовок стилем `headlineSmall` или `titleMedium`, пояснение стилем `bodyMedium` (до трёх строк), одна кнопка действия.

**Внешний вид.** Располагается по центру доступной области с внешними отступами 32 dp, максимальная ширина текста 320 dp, выравнивание по центру. Иллюстрации не используются.

**Состояния.**

| Экран | Заголовок | Пояснение | Действие |

| Главная | «Пока нет привычек на сегодня» | «Создайте первую привычку и отмечайте её каждый день» | «Создать привычку» |

### 4.9. DayBottomSheet

**Назначение.** Показ привычек выбранного дня в календаре и на тепловой карте статистики.

**Состав.** Ручка перетаскивания 32×4 dp, заголовок с датой стилем `titleMedium`, список `HabitStatusRow`, кнопка «Закрыть» для TalkBack.

**Внешний вид.** `ModalBottomSheet` с радиусом 28 dp сверху, фон `Surface`, внутренний отступ 16 dp, максимальная высота 80 % экрана, при большом числе привычек список прокручивается. Затемнение фона — 32 %.

**Состояния.**
- есть привычки — список со статусами;
- нет привычек — текст «В этот день привычек не было» без кнопок;

**Назначение.** Строка привычки со статусом в нижнем листе дня, истории и списке статистики.

**Состав.** Иконка привычки 24 dp в круге 32 dp, название стилем `bodyLarge` (одна строка), статус стилем `bodySmall`, при действии — круг отметки 40 dp.

**Внешний вид.** Высота 56 dp, разделитель `OutlineVariant` между строками, фон прозрачный. Статус «Выполнено» — `Success` с иконкой `Check`, «Пропущено» — `Error` с иконкой «минус», «Не отмечено» — `OnSurfaceVariant`, «Не запланировано» — `OnSurfaceVariant` с прозрачностью 60 %.

**Состояния.** Обычное, нажатое (`ripple`), недоступное для отметки (без круга). Для TalkBack строка объединяется и читается как «Зарядка, выполнено».

## 5. Основные экраны

Экраны описаны в порядке прохождения пользователем. Для каждого указаны расположение элементов, содержание, действия, переходы, пустое состояние и состояние загрузки. Схема навигации и маршруты — раздел 6; визуальные детали компонентов — раздел 4.

### 5.1. Приветственный экран (`onboarding`)

**Назначение.** Познакомить с приложением до первого взаимодействия с данными (FR-4.13.1).

**Расположение элементов (сверху вниз):**
1. панель без `TopAppBar`: текстовая кнопка «Пропустить» в правом верхнем углу, отступ 16 dp;
2. `HorizontalPager` на три страницы, занимающий центральную часть экрана;
3. индикатор страниц (точки) под текстом;
4. основная кнопка «Далее» / «Начать» шириной во весь экран с отступом 16 dp от низа и учётом системной вставки.

**Содержание страниц:**
- «Добро пожаловать» — LifeTrack помогает формировать привычки без интернета и аккаунта;
- «Отмечайте каждый день» — одно нажатие на карточке, серия и прогресс дня;
- «Напоминания и прогресс» — уведомление в выбранное время, календарь и статистика.

Каждая страница содержит крупную иконку 96 dp в круге `PrimaryContainer`, заголовок `headlineSmall` и 1–2 строки текста `bodyMedium`, выровненные по центру.

**Действия.** Свайп, «Далее», «Начать», «Пропустить». На последней странице кнопка меняет текст на «Начать».

**Переходы.** Любое завершение устанавливает `onboarding_completed = true` и открывает `home` с очисткой стека: возврат к приветственному экрану невозможен.

**Пустое состояние и загрузка.** Не предусмотрены: экран не зависит от данных. Ошибок нет.

### 5.2. Главный экран — «Сегодня» и «Все привычки» (`home`)

**Назначение.** Показать привычки на сегодня и позволить отметить выполнение в одно нажатие (NFR-4.2), а также дать доступ ко всем созданным привычкам, включая приостановленные (FR-4.4.7).

**Расположение элементов (сверху вниз):**
1. `TopAppBar`: заголовок «Сегодня», подзаголовок с датой «29 октября, четверг» стилем `bodySmall`, иконка настроек справа;
2. переключатель режимов «Сегодня» / «Все привычки» (FR-4.4.7) шириной во весь контент;
3. карточка прогресса дня (только в режиме «Сегодня»): текст «Выполнено 2 из 4», процент справа, линейный индикатор; при наличии серии — строка «Лучшая серия: 5 дней»; в режиме «Все привычки» вместо карточки выводится строка «Всего: 6 · активно: 4 · приостановлено: 2» стилем `bodyMedium`;
4. прокручиваемый список `LazyColumn` с группами по категориям: заголовок группы стилем `titleSmall` и счётчик «2 / 3» справа, ниже карточки `HabitCard` с отступом 8 dp;
5. `FloatingActionButton` с иконкой «+» в правом нижнем углу над нижней панелью.

**Содержание.** В режиме «Сегодня» — только активные привычки, запланированные на текущую дату (FR-4.4.1). В режиме «Все привычки» — все созданные привычки, включая приостановленные (US-34): приостановленные показываются приглушённо, с меткой «Приостановлена» и без круга отметки. Порядок: группы в порядке справочника категорий, внутри группы сначала активные привычки, затем приостановленные, внутри каждой части — по названию. Привычки без категории — в группе «Без категории» последней. Карточка содержит иконку в цветном круге, название, описание (одна строка, если заполнено), периодичность текстом, текущую серию и меню «…». Отмеченные привычки остаются на своих местах, название приглушается.

**Действия.** Переключение режимов; в режиме «Сегодня» — отметка и снятие `DONE` нажатием на круг, меню «…» («Отметить пропуск», «Редактировать», «Удалить»); нажатие на карточку — подробный экран (доступно в обоих режимах); кнопка «+» — создание привычки; иконка настроек — настройки.

**Переходы.** `habit_detail/{habitId}`, `habit_editor`, `habit_editor?habitId={habitId}`, `settings`. Переход на подробный экран — slide-in справа; возврат — slide-out вправо. Переключение режимов не меняет маршрут.

**Пустые состояния.**
- в режиме «Сегодня» привычек нет — `EmptyState` «Пока нет привычек на сегодня» с кнопкой «Создать привычку»;
- в режиме «Все привычки» привычек нет — `EmptyState` «Привычек пока нет» с кнопкой «Создать привычку»;
- все привычки на сегодня выполнены — сохранённый список и поздравление «Все привычки на сегодня выполнены» в карточке прогресса с иконкой `Check`.

**Загрузка.** Скелетоны переключателя режимов, карточки прогресса дня и трёх карточек высотой 88 dp; состояние показывается не дольше 300 мс, затем выводится контент или пустое состояние. FAB и верхняя панель активны.

**Ошибка.** `EmptyState` «Не удалось загрузить привычки» с кнопкой «Повторить»; кнопка создания привычки остаётся доступной.

**Обратная связь.** Snackbar над нижней панелью: «Привычка создана», «Привычка удалена», «Не удалось сохранить отметку», «Достижение получено: {название}».

### 5.3. Экран создания привычки (`habit_editor`)

**Назначение.** Создание привычки со всеми параметрами и проверкой корректности (FR-4.1.1, FR-4.1.2).

**Расположение элементов (сверху вниз):**
1. `TopAppBar`: кнопка «Назад», заголовок «Новая привычка», текстовая кнопка «Сохранить» справа;
2. прокручиваемая колонка с отступом 16 dp и `imePadding()`:
   - секция «Основное»: поле «Название» с подписью и счётчиком «0 / 60», многострочное поле «Описание» на 3–5 строк со счётчиком «0 / 255», ряд `CategoryChip` с горизонтальной прокруткой, включая «Без категории»;
   - секция «Оформление»: сетка иконок по 5 в ряд (ячейка 48 dp, выбранная — круг `PrimaryContainer` с обводкой `Primary` 2 dp), палитра из 12 цветов (круг 40 dp, выбранный — обводка 3 dp и иконка `Check`), предпросмотр карточки привычки в реальном времени;
   - секция «Периодичность»: сегментированный переключатель «Ежедневно / По дням недели / С интервалом»; для режима дней — 7 круглых чипов «Пн…Вс»; для интервала — счётчик «Каждые [3] дня» с кнопками «−» и «+» и полем числового ввода, диапазон 2…30;
   - секция «Напоминание»: компонент `ReminderTimePicker` с переключателем «Напоминать» и подсказкой о разрешении на уведомления;
   - секция «Активность»: отображается только при редактировании, содержит переключатель «Привычка активна».

**Содержание.** Значения по умолчанию: периодичность «Ежедневно» с отмеченными семью днями, иконка `star`, первый цвет палитры, напоминание выключено (09:00), категория «Без категории». Счётчики символов обновляются при вводе, превышение блокируется на уровне поля.

**Действия.** Ввод текста, выбор категории, иконки и цвета, выбор периодичности, включение напоминания и выбор времени, «Сохранить», «Назад».

**Валидация и обратная связь.**
- ошибки появляются после попытки сохранения или потери фокуса полем;
- текст ошибки — под соответствующим полем, цвет `Error`, обводка поля `Error`;
- кнопка «Сохранить» недоступна, пока форма невалидна или идёт запись;
- во время сохранения в кнопке отображается `CircularProgressIndicator` 20 dp, поля недоступны;
- при ошибке записи кнопка снова активна, показывается Snackbar «Не удалось сохранить привычку».

**Переходы.** Успешное сохранение закрывает экран и возвращает на главный экран с сообщением «Привычка создана». «Назад» при наличии изменений открывает диалог «Выйти без сохранения?» с вариантами «Остаться» и «Выйти».

**Пустое состояние.** Не применяется: форма всегда заполнена значениями по умолчанию.

**Загрузка.** Не требуется; при открытии формы из карточки привычки используется тот же экран редактирования.

### 5.4. Экран редактирования привычки (`habit_editor?habitId={habitId}`)

**Назначение.** Изменение параметров существующей привычки (FR-4.1.3).

**Расположение элементов.** Совпадает с экраном создания. Отличия:
- заголовок «Редактирование», в `TopAppBar` справа дополнительно меню «⋮» с пунктом «Удалить»;
- внизу формы секция «Активность» с переключателем «Привычка активна»;
- значения всех полей предзаполнены.

**Содержание.** Все поля заполнены текущими значениями, включая выбранные дни недели, интервал, иконку, цвет, категорию, время напоминания и признак активности. Если у привычки нет напоминания, переключатель «Напоминать» выключен, время — 09:00.

**Действия.** Сохранение, отмена, удаление через меню «⋮», изменение признака активности, выбор всех параметров. При изменении периодичности:
- сразу под сегментированным переключателем появляется плашка `WarningContainer` с текстом «Изменение периодичности влияет на расчёт статистики за прошлые периоды»;
- при нажатии «Сохранить» открывается диалог подтверждения с тем же текстом и кнопками «Отмена» и «Сохранить»;
- подтверждение сохраняет изменения, отмена возвращает к форме без потери введённых значений.

**Удаление.** Пункт «Удалить» в меню «⋮» открывает диалог «Удалить привычку?» с предупреждением о необратимости и кнопками «Отмена» / «Удалить».

**Переходы.** Сохранение закрывает экран и возвращает на подробный экран привычки с сообщением «Изменения сохранены». Если форма открыта из меню карточки, возврат выполняется на главный экран.

**Пустое состояние.** При отсутствии привычки по идентификатору показывается `EmptyState` «Привычка не найдена» с кнопкой «Назад»; форма не отображается.

**Загрузка.** Скелетон полей до получения данных привычки; кнопка «Сохранить» недоступна до окончания загрузки.

**Ошибка.** Сообщение «Не удалось загрузить привычку» с кнопкой «Повторить»; при ошибке сохранения — Snackbar и возврат к форме с сохранёнными введёнными значениями.

### 5.5. Экран подробной информации о привычке (`habit_detail/{habitId}`)

**Назначение.** Центральная точка работы с одной привычкой: статус, серия, история и действия.

**Расположение элементов (сверху вниз):**
1. `TopAppBar`: кнопка «Назад», название привычки (одна строка), меню «⋮» с пунктом «Удалить»;
2. шапка: круг 64 dp с иконкой привычки, название `headlineSmall`, чип категории, описание `bodyMedium`;
3. блок статуса: подпись «Активна» / «Приостановлена» с цветовой меткой, периодичность текстом, время напоминания или «Напоминание выключено»;
4. строка отметки за сегодня: круг 48 dp и статус «Выполнено» / «Не отмечено» / «Пропущено» / «Не запланировано»;
5. четыре карточки `StatisticsCard` в сетке 2×2: «Текущая серия», «Максимальная серия», «Процент за 30 дней», «Всего выполнений»;
6. секция «Последние 30 дней» — полоса из 30 сегментов высотой 24 dp;
7. секция «История выполнения» — список `HabitStatusRow` до 30 запланированных дней с датами;
8. нижняя панель действий: переключатель «Привычка активна» и кнопки «Редактировать» (тоновая), «Статистика» (контурная); удаление — в меню «⋮».

**Содержание.** Текущая и максимальная серия, статус за сегодня, сведения о периодичности и напоминании, история за последние 30 календарных дней (только запланированные дни). Для неактивной привычки текущая серия равна нулю, история сохраняется. Если напоминание включено, но системные уведомления отключены, под строкой «Напоминание» выводится плашка `WarningContainer` с кнопкой «Открыть настройки приложения».

**Действия.** Отметка и снятие выполнения за сегодня (если день запланирован), «Редактировать», «Статистика», переключение активности, удаление через меню.

**Переходы.** `habit_editor?habitId={habitId}`, `habit_statistics/{habitId}`, возврат на предыдущий экран. После удаления — возврат назад и сообщение «Привычка удалена».

**Пустое состояние.** Для привычки без отметок история заменяется текстом «Пока нет отметок. Начните с сегодняшнего дня»; серия равна `0`, полоса из 30 дней показывает нейтральные сегменты. Если привычка не найдена — возврат назад с сообщением «Привычка не найдена» (раздел 6.5 ТЗ).

**Загрузка.** Скелетон шапки и карточек метрик; кнопки недоступны до загрузки. Ошибка загрузки — сообщение и кнопка «Повторить».

**Удаление.** Диалог «Удалить привычку?» с текстом «История выполнения и настройки напоминания будут удалены безвозвратно. Полученные достижения останутся» и кнопками «Отмена» / «Удалить» (цвет `Error`).

### 5.6. Календарь (`calendar`)

**Назначение.** Обзор активности по дням месяца с возможностью посмотреть состав дня (FR-4.6).

**Расположение элементов (сверху вниз):**
1. `TopAppBar` «Календарь» с иконкой настроек;
2. панель месяца: «‹», «Октябрь 2026», «›», кнопка «Сегодня»;
3. строка дней недели «Пн … Вс»;
4. сетка `HabitCalendar` с ячейками дней;
5. легенда цветов в две строки стилем `bodySmall`;
6. `ModalBottomSheet` (`DayBottomSheet`) поверх экрана при выборе дня.

**Содержание.** Текущий месяц при открытии; отметки по всем активным привычкам, запланированным на день; выделение сегодняшнего дня; для будущих дней — только расписание.

**Действия.** Листание месяцев кнопками и свайпом, кнопка «Сегодня», выбор дня, просмотр статусов в нижнем листе, переход в подробный экран привычки, отметка за сегодня из нижнего листа (US-18).

**Переходы.** `habit_detail/{habitId}`, `settings`. Возврат из подробного экрана сохраняет выбранный месяц.

**Пустое состояние.**
- привычек нет вовсе — вместо сетки `EmptyState` «Нет данных для отображения» с кнопкой «Создать привычку»;
- в выбранном месяце нет отметок — сетка отображается, легенда и подпись «В этом месяце ещё нет отметок» под ней.

**Загрузка.** Сетка-скелетон и скелетон легенды; переключение месяцев доступно после загрузки. Ошибка — `EmptyState` «Не удалось загрузить календарь» с кнопкой «Повторить».

**Переход между месяцами.** Кроссфейд 150 мс; свайп влево открывает следующий месяц, вправо — предыдущий.

### 5.7. Общая статистика (`statistics`)

**Назначение.** Сводная аналитика по активным привычкам за выбранный период (FR-4.8.1–FR-4.8.4).

**Расположение элементов (сверху вниз):**
1. `TopAppBar` «Статистика», иконки «Как считается статистика» и настроек;
2. сегментированный переключатель «Неделя / Месяц / Всё время», по умолчанию «Неделя»;
3. главная карточка: процент выполнения стилем `displaySmall`, линейный индикатор, подпись периода («29 сентября — 29 октября»);
4. сетка карточек `StatisticsCard`: «Выполнено», «Пропущено», «Лучшая серия периода»;
5. диаграмма активности по выбранному периоду (FR-4.9);
6. блок «Лучшая привычка»: иконка, название, процент;
7. список активных привычек с мини-индикатором выполнения за период;
8. подсказка «Как считается статистика» в виде диалога.

**Содержание.** Проценты округляются до целого; будущие дни не учитываются; ожидаемые выполнения считаются с даты создания привычки. Если ожидаемые выполнения есть, а выполнений нет, процент равен `0 %`; если ожидаемых выполнений нет — «—». Выполнения учитываются только за запланированные дни. Неактивные привычки в общую статистику не входят, а после повторной активации снова учитываются с текущей даты; история их отметок при этом сохраняется. Период по умолчанию — неделя; выбор периода хранится только в состоянии экрана.

**Действия.** Смена периода, открытие статистики привычки, открытие подсказки, переход в настройки.

**Переходы.** `habit_statistics/{habitId}`, `settings`. Переключение периода не меняет маршрут и не перезагружает экран.

**Пустые состояния.**
- нет активных привычек — `EmptyState` «Нет активных привычек» с кнопкой «Создать привычку»;
- нет отметок за период — метрики равны нулю, процент `0 %` при ненулевых ожидаемых выполнениях (или «—», если ожидаемых выполнений нет), под диаграммой текст «Отмечайте привычки, чтобы увидеть статистику».

**Загрузка.** Скелетоны главной карточки, сетки метрик и области диаграммы; переключатель периода активен и сохраняет выбор.

**Ошибка.** `EmptyState` «Не удалось загрузить статистику» с кнопкой «Повторить».

**Особенности диаграмм.** Неделя — 7 столбцов высотой до 120 dp, подписи «Пн … Вс», проценты над столбцами. Месяц — тепловая карта с пятью уровнями прозрачности `Primary` (0 %, 1–33 %, 34–66 %, 67–99 %, 100 %). Всё время — столбцы по месяцам с сокращёнными подписями. Диаграммы не являются единственным способом получить данные: те же значения выводятся в карточках.

### 5.8. Статистика отдельной привычки (`habit_statistics/{habitId}`)

**Назначение.** Детальный анализ одной привычки (FR-4.8.5).

**Расположение элементов (сверху вниз):**
1. `TopAppBar`: «Назад», название привычки, действие «Редактировать»;
2. шапка: круг 56 dp с иконкой, название `headlineSmall`, чип категории;
3. главная карточка: процент выполнения за 30 дней стилем `displaySmall` и подпись «за последние 30 дней»;
4. сетка карточек: «Текущая серия», «Максимальная серия», «Выполнено всего», «Пропущено всего», «Процент за 7 дней», «Процент за всё время»;
5. тепловая карта за последние 30 дней;
6. столбчатая диаграмма по неделям текущего месяца;
7. нижний блок: «Создана» и «Последняя отметка» стилем `bodySmall`.

**Содержание.** Все значения рассчитываются из базы; для неактивной привычки текущая серия равна `0`, история и максимальная серия сохраняются. Пустые значения отображаются прочерком «—».

**Действия.** Только просмотр и переход к редактированию; изменения данных на экране невозможны.

**Переходы.** `habit_editor?habitId={habitId}`, возврат на предыдущий экран.

**Пустые состояния.** Нет отметок — проценты `0 %` при ненулевых ожидаемых выполнениях (если ожидаемых нет, показывается «—»), счётчики нулевые, тепловая карта нейтральная, подсказка «Отмечайте привычки, чтобы увидеть статистику». Привычка не найдена — `EmptyState` «Привычка не найдена» с кнопкой «Назад».

**Загрузка.** Скелетон шапки и карточек; ошибка — сообщение и кнопка «Повторить».

### 5.9. Достижения (`achievements`)

**Назначение.** Мотивация через визуализацию прогресса и полученных наград (FR-4.12).

**Расположение элементов (сверху вниз):**
1. `TopAppBar` «Достижения» с иконкой настроек;
2. блок прогресса: «Открыто 3 из 10» стилем `titleMedium`, справа «30 %», ниже линейный индикатор;
3. сетка `LazyVerticalGrid` из двух колонок с отступом 8 dp между карточками;
4. карточки `AchievementCard` в порядке справочника: сначала открытые, затем закрытые с прогрессом, затем условия-флаги.

**Содержание.** Десять стартовых достижений из раздела 3.6 ТЗ: иконка, название, условие, прогресс «X / Y» для измеримых условий, дата получения для открытых. Счётчик в заголовке обновляется сразу после разблокировки. Бейдж «Новое» показывается в текущей сессии.

**Действия.** Прокрутка, нажатие на карточку — диалог с подробным условием, переход в настройки.

**Переходы.** `settings`. Диалог не меняет маршрут.

**Пустые состояния.**
- все достижения закрыты — обычная сетка и подпись под прогрессом «Выполняйте привычки, чтобы открыть первое достижение»;
- все достижения открыты — сетка и плашка `SuccessContainer` «Все достижения получены» под блоком прогресса.

**Загрузка.** Сетка из четырёх карточек-скелетонов и скелетон блока прогресса. Ошибка — `EmptyState` «Не удалось загрузить достижения» с кнопкой «Повторить».

**Обратная связь.** При разблокировке — Snackbar «Достижение получено: {название}» или «Получено достижений: N»; на вкладке нижней навигации — бейдж с количеством новых достижений (не более «9+»).

### 5.10. Настройки (`settings`)

**Назначение.** Управление оформлением, напоминаниями и справочной информацией (раздел 6.10 ТЗ).

**Расположение элементов (сверху вниз):**
1. `TopAppBar` «Настройки» с кнопкой «Назад»;
2. секция «Оформление»: три строки с радиокнопками «Системная», «Светлая», «Тёмная», выбранная строка подсвечена `SecondaryContainer`;
3. секция «Напоминания»: строка с переключателем «Напоминания» и пояснением «Уведомления о привычках в выбранное время»;
4. при отключённых системных уведомлениях — плашка `WarningContainer` «Уведомления отключены в системе» с кнопкой «Открыть настройки приложения»;
5. секция «О приложении»: название LifeTrack, версия `1.0`, краткое описание, год разработки.

**Содержание.** Только перечисленные настройки. Выход из аккаунта, синхронизация, экспорт и сброс данных отсутствуют.

**Действия.** Выбор темы, глобальное включение и выключение напоминаний, переход в системные настройки приложения, возврат назад.

**Переходы.** «Назад» возвращает на экран, с которого открыты настройки. Переход в системные настройки выполняется через `Intent` и не меняет стек приложения.

**Пустое состояние.** Не применяется: экран всегда содержит настройки и сведения о приложении.

**Загрузка.** Кратковременная: строки-скелетоны секций до чтения DataStore. При ошибке чтения используются значения по умолчанию («Системная» тема, напоминания включены) без показа ошибки.

**Обратная связь.** Смена темы применяется мгновенно, без Snackbar; переключение напоминаний сопровождается пояснением под строкой «Напоминания отключены для всех привычек».

## 6. Навигация

### 6.1. Граф навигации

Навигация реализуется одним `NavHost` на Navigation Compose. Маршруты и их типы соответствуют разделу 6.1 ТЗ.

| Маршрут | Экран | Нижняя панель | Открытие |
|---|---|---|---|
| `onboarding` | Приветственный экран | Скрыта | Стартовый маршрут при `onboarding_completed = false` |
| `home` | Сегодня | Показана | Стартовый маршрут при `onboarding_completed = true`, вкладка 1 |
| `calendar` | Календарь | Показана | Вкладка 2 |
| `statistics` | Статистика | Показана | Вкладка 3 |
| `achievements` | Достижения | Показана | Вкладка 4 |
| `habit_editor` | Новая привычка | Скрыта | FAB на главной, пустые состояния |
| `habit_editor?habitId={habitId}` | Редактирование | Скрыта | Подробный экран, меню карточки |
| `habit_detail/{habitId}` | Подробности привычки | Скрыта | Главная, календарь, статистика, уведомление |
| `habit_statistics/{habitId}` | Статистика привычки | Скрыта | Статистика, подробности |
| `settings` | Настройки | Скрыта | Верхняя панель всех четырёх вкладок |

Нижняя панель отображается только для четырёх корневых маршрутов. Она входит в общий `Scaffold` и скрывается при переходе на полноэкранные маршруты; контент получает `innerPadding` и системные вставки.

### 6.2. Нижняя панель

| Позиция | Подпись | Маршрут | Иконка | Дополнительно |
|---|---|---|---|---|
| 1 | Сегодня | `home` | `Today` | — |
| 2 | Календарь | `calendar` | `CalendarMonth` | — |
| 3 | Статистика | `statistics` | `Insights` | — |
| 4 | Достижения | `achievements` | `EmojiEvents` | Бейдж с количеством новых достижений, не более «9+» |

Правила:
1. Подписи отображаются всегда; неактивный элемент — `OnSurfaceVariant`, активный — `Primary` с фоном `PrimaryContainer` у иконки.
2. Переход между вкладками выполняется через `popUpTo(home)` с `saveState = true` и `restoreState = true`; состояние прокрутки и выбранного периода сохраняется.
3. Повторное нажатие на активную вкладку прокручивает её содержимое в начало (раздел 6.1 ТЗ).
4. Нижняя панель не показывается на экранах онбординга, формы, подробностей, статистики привычки и настроек.
5. Snackbar отображается над нижней панелью и не перекрывает FAB.

### 6.3. Верхняя панель

- На всех четырёх вкладках справа есть иконка настроек — единственный вход в `settings`. На главном экране она обязательна; на остальных вкладках сохраняется для единообразия.
- На экранах формы, подробностей и статистики привычки слева расположена кнопка «Назад», справа — только действия, относящиеся к экрану.
- Заголовки: «Сегодня», «Календарь», «Статистика», «Достижения», «Настройки», «Новая привычка», «Редактирование»; на подробном экране — название привычки.
- Кнопки-иконки имеют размер 48 dp и `contentDescription`.

### 6.4. Правила переходов и возврата

1. Стартовый маршрут определяется флагом `onboarding_completed`: `false` → `onboarding`, `true` → `home`.
2. После завершения онбординга стек очищается: `onboarding` удаляется из back stack.
3. «Назад» на полноэкранном экране возвращает на предыдущий экран; на вкладке, отличной от «Сегодня», — переходит на `home`; на `home` — закрывает приложение.
4. Переходы между вкладками — `fade` 150 мс; открытие полноэкранного экрана — `slideInHorizontally` 250 мс, закрытие — обратный слайд.
5. Уведомление открывает `habit_detail/{habitId}`: `PendingIntent` передаёт `habitId`, после старта приложения выполняется навигация на подробный экран; при открытом приложении экран открывается поверх текущей вкладки.
6. Одинаковые маршруты не дублируются в стеке (`launchSingleTop = true`).
7. После удаления привычки из подробного экрана выполняется `popBackStack()` и показывается Snackbar на предыдущем экране.
8. Поворот экрана и смена конфигурации не сбрасывают стек навигации и состояние форм (для полей формы используется `rememberSaveable`).

## 7. Анимации

Анимации выполняются только средствами Compose (`animate*AsState`, `AnimatedVisibility`, `Crossfade`, `animateItem`). Сторонние библиотеки анимаций не подключаются. Длительность — 120–250 мс, динамика — `FastOutSlowInEasing` или `spring` с малой жёсткостью. Одновременно выполняется не более одной акцентной анимации.

Обязательный набор — четыре анимации. Он входит в объём MVP:

| Анимация | Где | Реализация | Длительность |
|---|---|---|---|
| Отметка выполнения | Круг `HabitCard`, круг в нижнем листе | `animateColorAsState` для заливки, `animateFloatAsState` для масштаба иконки `Check` (0,8 → 1,0) | 200 мс |
| Изменение прогресса | `ProgressIndicator`, карточка прогресса дня | `animateFloatAsState` для доли заполнения | 250 мс |
| Переходы | Нижняя навигация, `NavHost`, календарь | `Crossfade` между вкладками и месяцами, `slideInHorizontally` / `slideOutHorizontally` для полноэкранных маршрутов | 150–250 мс |
| Разблокировка достижения | `AchievementCard` | `animateColorAsState` фона и иконки, масштаб 1,0 → 1,05 → 1,0, затем Snackbar | 250 мс |

Дополнительные анимации не обязательны: они выполняются при наличии времени и не влияют на приёмку MVP.

| Анимация | Где | Реализация | Длительность |
|---|---|---|---|
| Появление карточек | Главная, календарь, достижения | `AnimatedVisibility` с `fadeIn` и `slideInVertically` при первом показе; новые элементы — `animateItem()` | 150 мс |
| Удаление элемента списка | Главная, история | `animateItem()` с `fadeOut` и `shrinkVertically` | 200 мс |
| Открытие нижнего листа | `DayBottomSheet` | Стандартная анимация `ModalBottomSheet` | 250 мс |
| Смена темы | Весь интерфейс | Интерполяция цветов Material 3 для ключевых поверхностей | 200 мс |

Ограничения:
1. Нет бесконечных и циклических анимаций, анимации печатающегося текста и эффектов при каждом обновлении данных из Flow.
2. Анимация не задерживает реакцию на нажатие: состояние меняется сразу, анимируется только визуальное представление.
3. При системном отключении анимаций интерфейс остаётся работоспособным: все изменения видны без промежуточных кадров.
4. `Snackbar` отображается 3–4 секунды над нижней панелью и FAB; диалоги закрываются по «Отмена» и по нажатию вне окна, что равнозначно отмене действия (раздел 6.11 ТЗ).

## 8. Адаптивность

### 8.1. Контрольные ширины

| Диапазон | Устройства | Раскладка |
|---|---|---|
| 360–430 dp | Смартфоны — основной приоритет, эталон дизайна | Одна колонка, отступы 16 dp |
| 320–359 dp | Компактные смартфоны | Та же одноколоночная раскладка; текстовый блок карточки сжимается, названия и описания обрезаются многоточием |
| 431–599 dp | Крупные смартфоны | Та же раскладка; увеличиваются внешние поля и максимальная ширина контента |
| 600–839 dp | Складные устройства, планшеты в портрете | Контент по центру, максимальная ширина 720 dp, карточки метрик по три в ряд |
| 840 dp и более | Планшеты в ландшафте | Контент по центру, максимальная ширина 840 dp, достижения в 4 колонки, календарь ограничен 560 dp |

Основной приоритет — смартфоны шириной 360–430 dp: на них проверяются все экраны и сценарии. Остальные размеры должны оставаться работоспособными за счёт той же одноколоночной раскладки и центрирования контента, без отдельного сложного интерфейса. Нижняя навигация сохраняется на всех размерах: переход к `NavigationRail` не предусмотрен, чтобы не усложнять MVP.

### 8.2. Поведение элементов

1. **Списки.** Одна колонка на смартфоне; на широких экранах карточки привычек остаются одной колонкой, так как содержат длинные названия.
2. **Формы.** Ширина полей ограничена 560 dp и центрируется; на смартфоне поля занимают всю доступную ширину.
3. **Календарь.** Сетка растягивается до 560 dp и центрируется; при большей ширине ячейки не увеличиваются сверх 56 dp.
4. **Диаграммы.** Высота 120 dp на смартфоне и 160 dp на широких экранах; ширина по контейнеру.
5. **Достижения.** Сетка с адаптивной минимальной шириной карточки 160 dp: 2 колонки на смартфоне, 3–4 на широких экранах.
6. **Кнопки.** Основные действия — шириной во весь контейнер на смартфоне; на широких экранах — не более 320 dp с выравниванием по левому краю.
7. **FAB.** Остаётся в правом нижнем углу над нижней панелью; на широких экранах — с отступом 24 dp от края контента.

### 8.3. Ориентация и системные элементы

1. Портретная ориентация — основная; ландшафт не блокируется (NFR-3.3).
2. В ландшафте контент прокручивается по вертикали, верхняя и нижняя панели остаются видимыми.
3. Приложение использует edge-to-edge: контент учитывает `statusBars`, `navigationBars` и вырезы экрана; фон панелей совпадает с `Surface`.
4. Клавиатура: форма использует `imePadding()`, поле в фокусе прокручивается в видимую область, кнопка «Сохранить» остаётся доступной.
5. Минимальная ширина поддерживаемого экрана — 320 dp; элементы не обрезаются и не перекрывают друг друга.

### 8.4. Масштабирование шрифта

1. Проверяется масштаб до 200 % (NFR-3.4).
2. Контейнеры текста не имеют фиксированной высоты: карточки и строки увеличиваются по содержимому.
3. Названия в карточках ограничены двумя строками с многоточием; важные значения (серия, процент) не обрезаются.
4. Горизонтальные ряды чипов прокручиваются; при нехватке места подписи нижней навигации допускают перенос на две строки.
5. Кнопки сохраняют минимальную высоту 48 dp и увеличиваются при необходимости.

### 8.5. Доступность одной рукой

1. Главное действие главного экрана — FAB «+» в правом нижнем углу.
2. Отметка выполнения — крупная зона 48 dp справа на карточке, достижимая большим пальцем.
3. Часто используемые действия в формах и диалогах располагаются в нижней части экрана.
4. Верхняя панель содержит только навигацию и вторичные действия.

### 9.5. Замечания по согласованию

1. **Динамическая палитра.** Текущая реализация `LifeTrackTheme` содержит параметр `dynamicColor = true`, тогда как FR-4.11.3 требует отказа от динамических цветов. Дизайн исходит из фиксированных палитр раздела 2; изменение выполняется на итерации 2 при настройке темы, исходный код в рамках аналитической итерации не изменяется.
2. **Значения по умолчанию формы.** В ТЗ не зафиксированы начальные значения иконки, цвета и периодичности. В дизайне приняты: иконка `star`, первый цвет палитры, «Ежедневно» с семью днями. Это не противоречит FR-4.1.2, где требуется лишь наличие выбранного значения.
3. **Порядок привычек.** ТЗ не задаёт сортировку внутри дня; в дизайне используется алфавитный порядок внутри категории. Правило не влияет на требования и может быть изменено без правок ТЗ.
4. **История на подробном экране.** Дизайн использует окно 30 календарных дней с отображением только запланированных дней, что согласовано с US-13.
5. **Режим «Все привычки».** Переключатель режимов относится к главному экрану итерации 3, хотя отметки и прогресс дня появляются на итерации 4. В режиме «Все привычки» блок прогресса дня заменяется счётчиком привычек, чтобы экран не показывал неактуальные нули.
6. **Серии и проценты.** Дизайн использует правила разделов 4.7 и 4.8 ТЗ: серия считается только по запланированным дням и не прерывается до конца текущего дня; процент равен `0 %` при ненулевых ожиданиях и «—» при их отсутствии.
